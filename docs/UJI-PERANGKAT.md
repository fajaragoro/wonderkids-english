# Daftar Uji di Perangkat Nyata

Uji ini perlu dilakukan langsung di HP/tablet karena suara, mikrofon, dan sentuhan berbeda tiap perangkat.
Unggah dulu ke hosting **HTTPS** (lihat README bagian "Mengunggah"), karena mikrofon dan mode offline butuh HTTPS.

Catat hasil per perangkat: ✅ lancar, ⚠️ ada masalah kecil, ❌ tidak jalan.

## Perangkat yang disarankan

| # | Perangkat | Browser | Catatan |
|---|---|---|---|
| 1 | HP Android (layar ±6") | Chrome | Perangkat utama anak |
| 2 | HP Android murah/lama (RAM 2–3 GB) | Chrome | Cek kelancaran animasi |
| 3 | iPhone | Safari | Suara dan mikrofon berperilaku beda di iOS |
| 4 | Tablet Android atau iPad | Chrome / Safari | Tegak dan mendatar |
| 5 | Laptop/PC | Chrome atau Edge | Mouse dan keyboard |

## 1. Masuk dan avatar

- [ ] Kode salah: kotak bergoyang, pesan ramah muncul, kolom kosong lagi.
- [ ] Kode `3016` benar: masuk. Tutup browser lalu buka lagi: langsung masuk tanpa kode.
- [ ] Tombol angka mudah ditekan jari anak (tidak salah tekan).
- [ ] Buat avatar Girl dengan kerudung dan Boy: pratinjau berubah setiap memilih.
- [ ] Bando/topi tidak bisa dipilih saat memakai kerudung.
- [ ] Nama panggilan maksimal 12 huruf, keyboard HP tidak menutupi tombol Simpan.

## 2. Peta dan tingkat

- [ ] Pilih tingkat 1, 2, 3: progres tiap tingkat terpisah.
- [ ] Peta bisa digulir dengan lancar; avatar berdiri di game yang sedang dikerjakan.
- [ ] Game terkunci menampilkan pesan, tidak bisa dibuka.

## 3. Suara (paling penting)

- [ ] Suara terdengar sejak sentuhan pertama (iOS kadang perlu satu sentuhan dulu).
- [ ] Bahasa terdengar Inggris (bukan logat Indonesia). Lihat nama suara di **Pengaturan**.
- [ ] Kecepatan bicara nyaman untuk anak.
- [ ] Pujian ("Great job!") tidak memotong kata yang sedang diucapkan.
- [ ] Tombol 🔊 "Dengarkan lagi" bekerja dan tidak membocorkan jawaban.
- [ ] Mode diam (silent) HP: catat apakah suara tetap keluar (iPhone dengan sakelar senyap biasanya tidak).
- [ ] Pengaturan > Suara: Mati benar-benar membisukan.

## 4. Mikrofon (Game 10)

- [ ] Izin mikrofon diminta sekali, lalu bisa dipakai.
- [ ] Ucapan yang benar dinilai benar; ucapan yang agak keliru tetap diterima (toleran).
- [ ] Ucapan yang sangat berbeda dinilai salah.
- [ ] Jika izin ditolak / tanpa internet: otomatis pindah ke mode pilih rekaman.
- [ ] Catat hasil di HP anak dengan suara anak (bukan suara orang dewasa) — ambang saat ini 60% kemiripan.

## 5. Setiap game (main minimal 1 stage di tiap game)

| Game | Cek khusus | Hasil |
|---|---|---|
| 1 Pasangkan | Kartu kata mudah dibaca | |
| 2 Susun Huruf | Huruf bisa dikembalikan dengan mengetuk kotak | |
| 3 Tebak Gambar | Ubin penutup terbuka pelan-pelan | |
| 4 Kalimat Rumpang | Kata masuk ke titik kosong | |
| 5 Pop Balon | Balon mudah diketuk walau bergerak; teks arti terbaca | |
| 6 Memory Card | Waktu mengintip kartu cukup (2,6 detik) | |
| 7 Dengarkan | Teks muncul setelah menjawab | |
| 8 Susun Kalimat | Kata bisa dikembalikan | |
| 9 Kejar Bintang | Animasi lari lancar, tidak patah-patah | |
| 10 Ulangi Yuk | Lihat bagian 4 | |

- [ ] Salah pertama: petunjuk muncul. Salah kedua: jawaban benar muncul dan tombol Lanjut.
- [ ] Ringkasan: bintang sesuai (9–10 = 3, 7–8 = 2, 5–6 = 1).
- [ ] Selesai semua stage satu game: game berikutnya terbuka dan hadiah item avatar muncul.

## 6. Tampilan dan sentuhan

- [ ] HP tegak dan mendatar: tidak ada bagian terpotong atau harus digeser ke samping.
- [ ] Tablet tegak dan mendatar nyaman.
- [ ] Tidak ada zoom tak sengaja saat mengetuk cepat.
- [ ] Tombol **Back** Android: kembali ke layar sebelumnya; di tengah stage muncul konfirmasi keluar.

## 7. Offline dan pasang di layar utama

- [ ] Menu browser > "Tambahkan ke layar utama": ikon Wonder Kids muncul.
- [ ] Buka dari ikon: tampil layar penuh tanpa bilah alamat.
- [ ] Setelah dibuka sekali, nyalakan mode pesawat: game masih bisa dimainkan (suara bawaan biasanya tetap jalan; mikrofon Game 10 pindah ke mode pilih).

## 8. Pengaturan

- [ ] Reset progres (dengan konfirmasi): bintang hilang, avatar tetap.
- [ ] Keluar: diminta kode lagi, progres tetap ada.
